# E42: บ้านตัวอย่างที่ปั้นทีละขั้นตามลำดับก่อสร้าง

บ้านชั้นเดียว 42 ตร.ม. หลังคาปั้นหยากระเบื้อง CPAC ปั้นครบ 15 ขั้น (ST00–ST14) แต่ละขั้นมีโมดูลเป็นของตัวเอง
มีตัวตรวจที่อ่านค่ากลับจากโมเดล และมีชุดเทสแบบจงใจทำผิด ใช้เป็นต้นแบบให้ Claude ดัดแปลงกับบ้านหลังอื่น

## สร้างทั้งหลัง

```bash
cd scripts
blender -b --factory-startup --python-exit-code 1 -P build_all.py
```

ใช้เวลาราว 2 นาที ไฟล์ที่ได้คือ `e42_house.blend` ในโฟลเดอร์นี้ ระหว่างสร้างจะพิมพ์ผลตัวตรวจของแต่ละขั้น
ถ้ามีขั้นไหนไม่ผ่าน คำสั่งจะหยุดพร้อมข้อความบอกว่าผิดตรงไหน

## รันเทส

หลังสร้างแล้ว เทสแต่ละชุดจะจงใจทำของผิดทีละอย่าง แล้วดูว่าตัวตรวจจับได้หรือไม่ รันจากโฟลเดอร์ `examples/e42`
(โฟลเดอร์เดียวกับ `e42_house.blend`)

```bash
cd ..
blender -b e42_house.blend --python-exit-code 1 -P scripts/test_units.py       # ประตูหน้าต่าง
blender -b e42_house.blend --python-exit-code 1 -P scripts/test_tiles.py       # กระเบื้อง
```

ผลอ่านจากข้อความที่พิมพ์ออกมา ทุกบรรทัดต้องเป็น `caught` หรือ `ok` ถ้ามีบรรทัด `MISSED` แปลว่าตัวตรวจปล่อยของผิดผ่าน
(เทสไม่ได้คืน exit code เมื่อเจอ MISSED)

งานไฟฟ้าแบ่งเทสเป็น 4 กลุ่ม คือ `"a"` `"b"` `"c"` `"rebuild"` เลือกกลุ่มด้วยตัวแปร `GROUP` ผ่าน `--python-expr`
(ถ้ารันด้วย `-P` จะได้กลุ่ม `"a"` เสมอ) บรรทัดสุดท้ายต้องเป็น `TESTS DONE … problems: 0`

```bash
blender -b e42_house.blend --python-exit-code 1 --python-expr 'GROUP = "c"; ONLY = None; exec(open("scripts/test_elec.py").read())'
```

กลุ่ม `"rebuild"` สร้างงานไฟฟ้าใหม่ 2 รอบต่อข้อ ตอนทำผิดและตอนคืนค่า (รอบละราว 90 วินาที) เลือกทีละข้อด้วย `ONLY = "<ส่วนหนึ่งของชื่อเทส>"`

## โครงไฟล์

| ไฟล์ | ขั้น |
|---|---|
| `scripts/e42_load.py` | โหลดทุกโมดูลตามลำดับ และหยุดทันทีถ้ามีชื่อฟังก์ชันหรือค่าคงที่ซ้ำกันข้ามไฟล์ |
| `scripts/e42_struct.py` | ST00–ST05 กริด ฐานราก ตอม่อ คานคอดิน พื้น เสา |
| `scripts/e42_walls.py` | ST06 ผนัง ฉาบ เซี้ยม อะเส ช่องเปิด |
| `scripts/e42_roof.py` `e42_roof_trim.py` `e42_fascia.py` | ST07 โครงหลังคา กระเบื้อง ครอบ ไม้เชิงชาย |
| `scripts/e42_ceiling.py` | ST08 ฝ้าและฝ้าชายคา |
| `scripts/e42_paint.py` | ST09, ST10, ST13 สีรองพื้นและสีทับหน้า |
| `scripts/e42_tiles.py` | ST11 บันได กันซึม กระเบื้อง บัวพื้น |
| `scripts/e42_elec.py` `e42_conduit*.py` | ST12 อุปกรณ์ วงจร ท่อร้อยสาย สายไฟ |
| `scripts/e42_units.py` | ST14 ประตู หน้าต่าง อลูมิเนียม กระจก |
| `scripts/e42_gb_design.py` | เลือกชนิดคานคอดินด้วยวิธี WSD |
| `ST12_conduit_spec.md` `ST14_doors_windows_spec.md` | บันทึกการตัดสินใจและบทเรียนของงานไฟฟ้าและประตูหน้าต่าง |

บ้านหลังนี้เริ่มจาก massing model (`e42_build.py` และ `e42_render.py`) ที่ไม่ได้ใส่มาในชุด ชื่อสองไฟล์นี้ที่เห็นในคอมเมนต์และ spec
หมายถึงโมเดลตั้งต้นนั้น ส่วนโค้ดที่จัดการของเก่าจากโมเดลนั้น (เช่น ซ่อนช่องเปิดเดิม ย้ายโครงสร้างเก่าไปคอลเลกชัน OLD)
จะข้ามไปเองเมื่อไม่มีของเหล่านั้นในไฟล์

ค่าที่ตั้งไว้ในโค้ด เช่น ขนาดห้อง ตำแหน่งปลั๊ก และรุ่นสินค้า เป็นของบ้านหลังนี้ เวลาใช้กับบ้านหลังอื่นให้ Claude
ถามสเปกของคุณทีละขั้นแล้วแก้ค่าเหล่านั้น
