# BOQ coverage: what each BOQ line needs from the construction model

Read before the first stage of a construction model, and again before a take-off script. Every line of a Thai single-storey BOQ template (CPAC roof; tabs งานโครงสร้าง · งานสถาปัตยกรรม · งานสุขาภิบาล ·
งานระบบไฟฟ้า) must come from a stage of the model or be marked as not modelled with its reason.
Worked out on SS-02 (4 พ.ย. 69), against a model with ST00–ST15 built. "Gap" = the line had nothing in that model; ST16–ST18 then
filled them (stage-sanitary.md). Check an earlier stage before calling a line a gap: the ceiling wool was in ST08 all along.

## How to use it

- Before a new model, read the template's four tabs (exported values) and tick each line against the stages planned.
- A line the drawings don't cover goes to the user as a question, not a silent zero.
- When a stage closes, its spec lists the BOQ lines it feeds (row text as in the template), so a take-off script can map
  objects to rows without guessing.
